# 🏛️ Руководство для учителей

## Создание контрольных работ

### Доступ к функционалу

Для доступа к управлению контрольными работами перейдите по адресу:

```
/teacher/lessons
```

**Важно:** Доступ имеют только пользователи с правами учителя (`is_teacher = true` в таблице `users`).

### Создание новой контрольной работы

1. Перейдите на страницу `/teacher/lessons`
2. Нажмите кнопку **"➕ Создать контрольную работу"**
3. Заполните форму:

#### Обязательные поля:

- **Название** — название контрольной работы (например: "Контрольная работа № 1")
- **Дата** — дата проведения контрольной работы

#### Опциональные поля:

- **Номер урока** — номер для связи с генератором заданий (`Lesson{N}Generator`)
- **Описание** — краткое описание урока
- **Теоретический материал** — теория к уроку
- **Активная** — чекбокс, определяющий, будут ли ученики видеть и решать этот урок

4. Нажмите **"✅ Создать"**

### Редактирование контрольной работы

1. На странице `/teacher/lessons` найдите нужный урок
2. Нажмите кнопку **"✏️ Редактировать"**
3. Внесите необходимые изменения
4. Нажмите **"✏️ Сохранить"**

### Удаление контрольной работы

1. На странице `/teacher/lessons` найдите нужный урок
2. Нажмите кнопку **"🗑️ Удалить"**
3. Подтвердите удаление

**Внимание:** Удаление урока безвозвратно!

## Статусы уроков

- **✔️ Активен** — ученики видят урок и могут его решать
- **❌ Неактивен** — урок скрыт от учеников

## Технические детали

### Маршруты

```php
GET  /teacher/lessons          # Список уроков
GET  /teacher/lessons/create   # Форма создания
POST /teacher/lessons          # Сохранение
GET  /teacher/lessons/{id}/edit # Форма редактирования
PUT  /teacher/lessons/{id}     # Обновление
DELETE /teacher/lessons/{id}   # Удаление
```

### Структура файлов

```
app/Http/Controllers/
└── TeacherController.php

resources/views/teacher/lessons/
├── index.blade.php   # Список уроков
├── create.blade.php  # Форма создания
└── edit.blade.php    # Форма редактирования
```

### Настройка прав доступа

Чтобы дать пользователю права учителя, выполните SQL-запрос:

```sql
UPDATE users SET is_teacher = 1 WHERE email = 'ЭЛЕКТРОННАЯ_ПОЧТА_УЧИТЕЛЯ';
```

Или через Laravel Tinker:

```php
$user = App\Models\User::where('email', 'ЭЛЕКТРОННАЯ_ПОЧТА')->first();
$user->is_teacher = true;
$user->save();
```
